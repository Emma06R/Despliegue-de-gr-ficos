Rana loca

Una rana verde vista de frente: cara, cuencas de los ojos, ojos blancos con pupilas cuadradas y una boca negra.

Proyecto original en Khan Academy: abrir el programa original. Aquí está adaptado a una página web estándar con p5.js.

Código

Este es el programa (archivo sketches/rana.js). La función dibujo() contiene los mismos comandos que escribí en Khan Academy; js/lienzo.js crea el lienzo de 400 × 400 y la llama.

// Rana loca (derivado de Khan Academy) — lienzo 400 x 400
function dibujo() {
  var x = 200;
  var y = 250;

  noStroke();
  fill(30, 204, 91); // a nice froggy green!

  ellipse(x, y, 200, 100); // face
  ellipse(x - 50, y - 50, 40, 40); // left eye socket
  ellipse(x + 50, y - 50, 40, 40); // right eye socket

  fill(255, 255, 255); // for the whites of the eyes!
  ellipse(x - 50, y - 50, 30, 30); // left eyeball
  ellipse(x + 50, y - 50, 30, 30); // right eyeball

  fill(0, 0, 0);
  ellipse(x, y, 100, 50);

  rect(x - 55, y - 55, 10, 10);
  rect(x + 45, y - 55, 10, 10);
}

Comandos que se usan

ComandoQué hace
noStroke()Quita el contorno de las formas que se dibujen a partir de ese momento.
fill(r, g, b)Define el color de relleno (0 a 255 por canal). Todo lo que se dibuje después usa ese color.
ellipse(x, y, ancho, alto)Dibuja una elipse centrada en (x, y). Ancho y alto son diámetros.
rect(x, y, ancho, alto)Dibuja un rectángulo; (x, y) es la esquina superior izquierda.

Qué observar

  • Las variables x e y son el centro de la rana: si cambias sus valores, toda la rana se mueve porque cada forma se calcula a partir de ellas (x - 50, y + 50…).
  • El orden importa: primero se pinta la cara verde, luego los ojos blancos encima y al final las pupilas. Lo último que se dibuja queda por delante.
