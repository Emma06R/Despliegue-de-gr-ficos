Dientes de conejo

Un conejo con orejas largas, cara redonda, ojos negros, boca y dos dientes grandes dibujados solo con contorno.

Proyecto original en Khan Academy: abrir el programa original. Aquí está adaptado a una página web estándar con p5.js.

Código

Este es el programa (archivo sketches/dientes-conejo.js). La función dibujo() contiene los mismos comandos que escribí en Khan Academy; js/lienzo.js crea el lienzo de 400 × 400 y la llama.

// Dientes de conejo (derivado de Khan Academy) — lienzo 400 x 400
function dibujo() {
  var eyeSize = 20;
  var toothLenght = 30;
  ellipse(150, 70, 60, 120); // left ear
  ellipse(240, 70, 60, 120); // right ear

  ellipse(200, 170, 150, 150); // face

  fill(0, 0, 0);
  ellipse(170, 150, eyeSize, eyeSize); // left eye
  ellipse(230, 150, eyeSize, eyeSize); // right eye

  line(150, 200, 250, 200); // mouth

  noFill();
  rect(185, 200, 15, toothLenght); // left tooth
  rect(200, 200, 15, toothLenght); // right tooth
}

Comandos que se usan

ComandoQué hace
var nombre = valorDeclara una variable. Aquí eyeSize y toothLenght controlan el tamaño de los ojos y el largo de los dientes.
ellipse(x, y, ancho, alto)Orejas, cara y ojos.
line(x1, y1, x2, y2)Línea recta entre dos puntos: la boca.
noFill()Hace que las formas siguientes no tengan relleno, solo contorno: así se ven los dientes.

Qué observar

  • Cambiando eyeSize o toothLenght en una sola línea se modifican los dos ojos o los dos dientes a la vez: ese es el beneficio de usar variables.
  • Las orejas y la cara se ven blancas porque todavía no se ha llamado a fill(): por defecto el relleno es blanco y el contorno negro. Los dientes usan noFill(), por eso solo se ve su contorno.
