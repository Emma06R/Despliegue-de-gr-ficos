# Dibujos con canvas y p5.js

Sitio web hecho con **HTML, CSS y JavaScript** que reúne cinco proyectos de Khan Academy
adaptados con [p5.js](https://p5js.org/):

1. Rana loca
2. Dientes de conejo
3. ¿Qué hay de cena?
4. Día nevado soleado
5. Muñeco de nieve que saluda

Incluye además:

- **canvas.html**: teoría de la etiqueta `<canvas>` y su contexto de renderizado 2D.
- **p5.html**: fundamentos de p5.js.
- **dom-inspector.html**: visualizador gráfico del árbol DOM de cada página.

## Estructura

```
index.html            página principal
*.html                dibujos y secciones teóricas
css/estilos.css       estilos
js/                   p5.min.js, lienzo.js, demos e inspector del DOM
sketches/             código de cada dibujo
```

## Ver el sitio en tu computadora

Abre una terminal en esta carpeta y ejecuta `python -m http.server 8000`; luego visita
http://localhost:8000. (El inspector DOM necesita un servidor: no funciona abriendo el archivo con doble clic.)
