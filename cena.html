¿Qué hay de cena?

Un plato rosa claro sobre un mantel gris con una porción de comida café, visto desde arriba.

Proyecto original en Khan Academy: abrir el programa original. Aquí está adaptado a una página web estándar con p5.js.

Código

Este es el programa (archivo sketches/cena.js). La función dibujo() contiene los mismos comandos que escribí en Khan Academy; js/lienzo.js crea el lienzo de 400 × 400 y la llama.

// ¿Qué hay de cena? (derivado de Khan Academy) — lienzo 400 x 400
function dibujo() {
  noStroke();
  background(200, 200, 200);

  //Plato
  fill(255, 225, 255);
  ellipse(200, 200, 300, 300);

  //Comida
  fill(139, 69, 19);
  rect(130, 180, 80, 40);
}

Comandos que se usan

ComandoQué hace
background(r, g, b)Pinta todo el lienzo con un color (el «mantel»).
noStroke()Sin contorno en las formas.
ellipse(200, 200, 300, 300)Un círculo grande en el centro del lienzo: el plato.
rect(130, 180, 80, 40)Un rectángulo café (139, 69, 19) que representa la comida.

Qué observar

  • Los comentarios //Plato y //Comida dividen el programa en partes. Es una buena práctica para que el código se pueda leer.
  • Si quieres cambiar de cena, solo hay que editar las líneas de «Comida»: añadir más formas con otros fill().
