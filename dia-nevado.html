Día nevado soleado

Un paisaje con cielo cian, suelo verde agua, un sol amarillo y un muñeco de nieve de tres bolas.

Proyecto original en Khan Academy: abrir el programa original. Aquí está adaptado a una página web estándar con p5.js.

Código

Este es el programa (archivo sketches/dia-nevado.js). La función dibujo() contiene los mismos comandos que escribí en Khan Academy; js/lienzo.js crea el lienzo de 400 × 400 y la llama.

// Día nevado soleado (derivado de Khan Academy) — lienzo 400 x 400
function dibujo() {
  // The ground
  fill(133, 255, 233);
  background(0, 255, 255);
  rect(0, 300, 400, 100);

  // The sun
  fill(251, 255, 0);
  ellipse(80, 64, 100, 100);

  // The snowman
  fill(245, 240, 240);
  ellipse(200, 300, 150, 150);
  ellipse(200, 200, 100, 100);
  ellipse(200, 120, 75, 75);
}

Comandos que se usan

ComandoQué hace
background(0, 255, 255)Pinta el cielo cian.
fill(r, g, b)Colores del suelo, del sol y de la nieve.
rect(0, 300, 400, 100)El suelo: ocupa todo el ancho (400) desde y = 300.
ellipse(...)Sol y tres bolas del muñeco (de 150, 100 y 75 px de diámetro).

Qué observar

  • Aunque fill() se escribe antes que background(), el color de relleno no se pierde: background() pinta el fondo, pero el último fill() sigue activo para el rectángulo del suelo.
  • El muñeco se dibuja de abajo hacia arriba: la bola grande en y = 300, la mediana en y = 200 y la cabeza en y = 120.
