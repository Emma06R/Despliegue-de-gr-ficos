La etiqueta <canvas> y el contexto 2D

HTML5 incorporó el elemento <canvas>, una superficie rectangular en la que JavaScript puede dibujar gráficos al instante: figuras, texto, imágenes y animaciones. Es la base sobre la que trabaja p5.js.

1. ¿Qué es <canvas>?

Es un elemento HTML que, por sí mismo, no dibuja nada: solo reserva un área de píxeles (un mapa de bits). Para pintar sobre ella se usa JavaScript y una API de dibujo. A diferencia de SVG, que guarda objetos que pueden volver a seleccionarse, el canvas es un modo inmediato: lo que se dibuja se convierte en píxeles y el navegador no recuerda las formas individuales. Si se quiere mover algo, se borra y se vuelve a dibujar.

El contenido escrito dentro de las etiquetas <canvas>…</canvas> es un contenido alternativo que solo se muestra en navegadores sin soporte o lo leen los lectores de pantalla.

2. Sintaxis y tamaño

<canvas id="miLienzo" width="400" height="400">
  Tu navegador no admite canvas. (Texto alternativo)
</canvas>
  • width y height son atributos que fijan el tamaño real del bitmap en píxeles. Si se omiten, el lienzo mide 300 × 150.
  • Darle tamaño con CSS solo escala la imagen y puede deformarla o verse borrosa. Por eso conviene usar los atributos.
  • Cambiar width o height por JavaScript borra el contenido del lienzo.

3. Contexto de renderizado: getContext()

Para dibujar hay que pedirle al canvas un contexto de renderizado, el objeto que ofrece los métodos de dibujo:

const lienzo = document.getElementById('miLienzo');
const ctx = lienzo.getContext('2d');   // contexto 2D

El argumento indica qué tipo de contexto se quiere:

ValorResultado
'2d'CanvasRenderingContext2D: dibujo bidimensional (formas, texto, imágenes). Es el que usan estos proyectos.
'webgl' / 'webgl2'Gráficos 3D acelerados por la GPU (basados en OpenGL ES).
'bitmaprenderer'Muestra mapas de bits (ImageBitmap) de forma eficiente.
'webgpu'Contexto de la API WebGPU, más moderna que WebGL.

Un canvas solo puede tener un tipo de contexto: si ya se pidió '2d', pedir 'webgl' sobre el mismo elemento devuelve null. También devuelve null si el navegador no soporta ese contexto, por eso es útil comprobar if (lienzo.getContext) o que el resultado no sea nulo.

4. Sistema de coordenadas

El origen (0, 0) está en la esquina superior izquierda. El eje x crece hacia la derecha y el eje y crece hacia abajo (al revés que en matemáticas). En un lienzo de 400 × 400, el centro es el punto (200, 200). Puedes comprobarlo con la rejilla de cualquiera de las páginas de dibujos, por ejemplo en la del muñeco de nieve.

5. API del contexto 2D

GrupoMétodos y propiedades principales
RectángulosfillRect(x, y, w, h), strokeRect(...), clearRect(...)
Trayectorias (paths)beginPath(), moveTo(x, y), lineTo(x, y), arc(x, y, r, a0, a1), ellipse(x, y, rx, ry, rot, a0, a1), closePath(), fill(), stroke()
Colores y estilosfillStyle, strokeStyle, lineWidth, globalAlpha, gradientes (createLinearGradient)
Textofont, fillText(texto, x, y), strokeText(...)
Transformacionestranslate(), rotate(), scale(), save(), restore()
Imágenes y píxelesdrawImage(), getImageData(), putImageData()

Ejemplo de una trayectoria: primero se describe la figura y después se rellena o se traza su contorno.

ctx.beginPath();          // empieza una figura nueva
ctx.moveTo(60, 190);      // punto inicial
ctx.lineTo(160, 40);      // línea hasta...
ctx.lineTo(260, 190);
ctx.closePath();          // cierra el triángulo
ctx.fillStyle = '#2563eb';
ctx.fill();               // rellena
ctx.lineWidth = 4;
ctx.strokeStyle = '#1e3a8a';
ctx.stroke();             // dibuja el contorno
Un triángulo azul y un arco rojo.

6. Equivalencias entre p5.js y el contexto 2D

p5.js dibuja sobre un canvas con esta misma API, así que cada comando de p5.js se puede traducir:

p5.js (Khan Academy)Canvas 2D nativo
fill(30, 204, 91)ctx.fillStyle = 'rgb(30, 204, 91)'
rect(x, y, w, h)ctx.fillRect(x, y, w, h)
ellipse(x, y, w, h)ctx.beginPath(); ctx.ellipse(x, y, w/2, h/2, 0, 0, 2*Math.PI); ctx.fill();
line(x1, y1, x2, y2)ctx.beginPath(); ctx.moveTo(x1, y1); ctx.lineTo(x2, y2); ctx.stroke();
noStroke()simplemente no llamar a ctx.stroke()
background(r, g, b)ctx.fillStyle = 'rgb(...)'; ctx.fillRect(0, 0, ancho, alto);

Observa que ellipse() de p5.js recibe diámetros (ancho y alto) mientras que ctx.ellipse() recibe radios.

7. Demostración: la rana en canvas puro

Este es el mismo dibujo de la rana, pero sin p5.js: solo <canvas> y getContext('2d').

Una rana verde.
const ctx = document.getElementById('demo-rana').getContext('2d');

// función auxiliar: igual que ellipse() de p5.js (w y h son diámetros)
function elipse(ctx, x, y, w, h) {
  ctx.beginPath();
  ctx.ellipse(x, y, w / 2, h / 2, 0, 0, Math.PI * 2);
  ctx.fill();
}

const x = 200, y = 250;
ctx.fillStyle = 'rgb(30, 204, 91)';
elipse(ctx, x, y, 200, 100);              // cara
elipse(ctx, x - 50, y - 50, 40, 40);      // cuenca izquierda
elipse(ctx, x + 50, y - 50, 40, 40);      // cuenca derecha
ctx.fillStyle = 'white';
elipse(ctx, x - 50, y - 50, 30, 30);      // ojo izquierdo
elipse(ctx, x + 50, y - 50, 30, 30);      // ojo derecho
ctx.fillStyle = 'black';
elipse(ctx, x, y, 100, 50);               // boca
ctx.fillRect(x - 55, y - 55, 10, 10);     // pupila izquierda
ctx.fillRect(x + 45, y - 55, 10, 10);     // pupila derecha

8. Animación

Para animar se repite un ciclo: borrar → actualizar posiciones → dibujar. El navegador ofrece requestAnimationFrame(), que ejecuta una función justo antes de cada repintado (normalmente 60 veces por segundo). Esto es lo que hace p5.js por dentro con su función draw().

Una pelota rebotando.

function frame() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);  // 1. borrar
  x += vx; y += vy;                                  // 2. actualizar
  if (x < r || x > canvas.width - r) vx = -vx;       //    (rebote)
  ctx.beginPath();
  ctx.arc(x, y, r, 0, Math.PI * 2);                  // 3. dibujar
  ctx.fill();
  requestAnimationFrame(frame);                      // 4. repetir
}
frame();

9. Buenas prácticas

  • Accesibilidad: añade contenido alternativo dentro de <canvas>, y role="img" con aria-label para describir el dibujo.
  • Nitidez en pantallas de alta densidad: usa window.devicePixelRatio para multiplicar el tamaño real del bitmap y escalar el contexto.
  • Usa save() y restore() para no arrastrar estilos o transformaciones a otros dibujos (p5.js hace lo mismo con push() y pop()).
  • Un solo contexto por canvas y pide el contexto una vez, guardándolo en una variable.
