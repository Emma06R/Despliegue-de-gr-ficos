Fundamentos de p5.js

p5.js es una librería de JavaScript de código abierto para programación creativa. Es la versión web de Processing (creado por Casey Reas y Ben Fry) y la inició Lauren Lee McCarthy en 2013; hoy la mantiene la Processing Foundation. Su objetivo es que dibujar, animar e interactuar con el navegador sea fácil para principiantes, artistas y estudiantes.

1. Cómo se incluye en una página

Basta con cargar el archivo de la librería antes de tu código. En este sitio se usa una copia local (js/p5.min.js, versión 1.9.4), de modo que funciona aunque no haya conexión a una CDN:

<script src="js/p5.min.js"></script>   <!-- 1. la librería -->
<script src="sketches/rana.js"></script> <!-- 2. tu dibujo -->

2. La estructura: setup() y draw()

  • setup() se ejecuta una sola vez al empezar: aquí se crea el lienzo con createCanvas(ancho, alto).
  • draw() se ejecuta en bucle, por defecto unas 60 veces por segundo, y es donde se dibuja y se anima.
  • noLoop() detiene ese bucle (se dibuja una sola vez); loop() lo reanuda y redraw() fuerza un nuevo dibujo.
function setup() {
  createCanvas(400, 400);
  noLoop();                 // dibujo estático
}

function draw() {
  background(255);
  ellipse(200, 200, 100, 100);
}

Los cinco dibujos de este sitio son estáticos, así que usan noLoop() (ver js/lienzo.js).

3. Modo global y modo instancia

En modo global (el predeterminado) las funciones setup, draw, ellipse… son globales y se escriben directamente. En modo instancia todo cuelga de un objeto p, lo que permite tener varios sketches en la misma página sin que se mezclen:

new p5(function (p) {
  p.setup = function () { p.createCanvas(400, 240); };
  p.draw  = function () { p.background(240); p.ellipse(p.mouseX, p.mouseY, 50, 50); };
}, 'demo-p5');   // id del contenedor

4. Lienzo y coordenadas

createCanvas(400, 400) crea un <canvas> de 400 × 400 píxeles y lo agrega a la página (con .parent('lienzo') se elige en qué contenedor). Las variables width y height guardan su tamaño. El origen (0, 0) está en la esquina superior izquierda y y crece hacia abajo.

6. Color y estilo

  • background(r, g, b): pinta todo el fondo. Los valores van de 0 a 255 (modo RGB).
  • fill(r, g, b) / noFill(): color de relleno de las formas siguientes, o sin relleno.
  • stroke(r, g, b) / noStroke(): color del contorno, o sin contorno. strokeWeight(n) define su grosor.
  • Con un solo número se obtiene un gris: fill(200). Un cuarto valor es la transparencia (alfa).

p5.js funciona como una máquina de estados: fill() cambia el color y se mantiene hasta que se vuelva a cambiar. Por eso el orden de las líneas importa. Lo último en dibujarse queda por encima (como pintar con capas).

7. Variables

Una variable guarda un valor con nombre para reutilizarlo. En el proyecto de la rana, x e y son el centro de la cara y todas las demás formas se calculan a partir de ellas (x - 50); en el conejo, eyeSize controla el tamaño de los dos ojos. En JavaScript moderno se prefieren let y const, aunque var sigue funcionando.

8. Interacción y animación

p5.js ofrece variables del sistema y eventos listos para usar:

  • mouseX, mouseY: posición del ratón; mousePressed(), keyPressed(): eventos.
  • frameCount: número de fotogramas dibujados; sirve para animar con sin() o contadores.
  • map(valor, a, b, c, d): convierte un valor de un rango a otro.

Las páginas de dibujos incluyen una interacción sencilla: mouseMoved() muestra las coordenadas del ratón sobre el lienzo, y una casilla para mostrar una rejilla.

9. Relación con <canvas>

p5.js no sustituye al canvas: lo envuelve. Internamente crea un <canvas> y llama a la API del contexto 2D descrita en la sección de canvas. Esto se puede ver con el inspector del DOM, donde el canvas aparece dentro del contenedor del dibujo. Además, la variable drawingContext da acceso directo al contexto 2D nativo:

function draw() {
  drawingContext.shadowBlur = 20;       // función del contexto 2D, no de p5
  drawingContext.shadowColor = 'gray';
  ellipse(200, 200, 100, 100);
}

10. Cómo se adaptó el código de Khan Academy

Khan Academy usa ProcessingJS, que tiene casi los mismos comandos que p5.js. Para llevar los programas a una página web propia solo hizo falta:

  1. Poner las instrucciones del dibujo dentro de una función (dibujo()), que se llama desde draw().
  2. Crear el lienzo de 400 × 400 con createCanvas(), porque en Khan Academy ya viene creado.
  3. Pintar un fondo blanco con background(255) antes del dibujo: en Khan Academy el fondo es blanco, pero en p5.js es gris por defecto.
  4. Cargar p5.min.js en un <script> y mostrar el lienzo dentro de un <div id="lienzo">.

Los comandos ellipse, rect, line, fill, noStroke, noFill y background quedaron exactamente igual.

11. Demostración interactiva

Mueve el ratón sobre el lienzo: el círculo lo sigue y cambia de color; el círculo verde pulsa con frameCount; haz clic para dejar puntos rojos.
